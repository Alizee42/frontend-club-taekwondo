// Documentation d'utilisation du composant ui-title

 * Utilisation de base :
 * <ui-title text="Gestion des commandes"></ui-title>
 *
 * Personnalisation :

 * <ui-title text="Gestion des paiements" level="2" align="left" [gradient]="false"></ui-title>
 *
 * Inputs disponibles :
 * - text : string (obligatoire)
 * - level : 1|2|3|4|5|6 (optionnel, par défaut 2)
 * - align : 'left'|'center'|'right' (optionnel, par défaut 'left')
 * - gradient : boolean (optionnel, par défaut true)
 *
 * Pour l'utiliser, importe UiTitleComponent dans ton composant ou module.
